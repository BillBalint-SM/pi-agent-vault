# Scoped lessons

## L-001 – Technical success is not design evidence

Context: the BontaFlow content adapter passed 10 offline tests. Evidence scope: argument validation, budget-estimate checks and approval gates. No generated image or video had been reviewed.

Correction: always report technical checks separately from visual, user and business evidence. Status: process correction adopted; positive user/business impact not measured.

## L-002 – A logo material study is not a complete brand system

Context: the supplied matte logo initially informed a matte-led concept. The existing canonical DESIGN.md also requires Prism illuminated glass and emerald/mint depth.

Correction: read the full owning design rules and medium boundaries before generalizing from one reference. Use the logo PNG for material reference and the production SVG for exact lettering. Status: local brief corrected; rendered outcome not yet validated.

## L-003 – Separation requires load controls as well as folders

Context: Pi skills must be separate from other agents' shared skills.

Correction: store Pi-only skills under this vault's `skills/`, explicitly allowlist each in Pi settings and preserve the global exclusion. Status: the portable profile passed isolated and saved-live-profile SDK resource-loading checks, including exactly two allowlisted skills. Current-session reload and other operating systems are separate checks; see `state/CURRENT.md`.
